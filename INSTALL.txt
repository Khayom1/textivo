TEXTIVO — INSTALLATION GUIDE v12

Requirements:
- Python 3
- Modern web browser

RUN WITH TERMUX:

1. Open the project directory:
   cd ~/textivo

2. Start the local server:
   python -m http.server 8080 --bind 127.0.0.1

3. Open in your browser:
   http://127.0.0.1:8080

Keep Termux running while using Textivo.
Press CTRL+C to stop the server.
