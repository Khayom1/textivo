TEXTIVO — INSTALLATION GUIDE v13

REQUIREMENTS
- Python 3
- A modern browser (Chrome, Firefox, Edge, or Safari)

RUN ON ANDROID WITH TERMUX

1. Open the project folder:
   cd ~/textivo

2. Start the local web server:
   python -m http.server 8080 --bind 127.0.0.1

3. Open in your browser:
   http://127.0.0.1:8080

Keep Termux running while using the local server.
Press CTRL+C to stop the server.

QUICK START
- Choose one of the built-in design templates.
- Edit the text and style selected words or characters.
- Select a canvas format: 16:9, 1:1, 9:16, or 4:5.
- Preview the composition and configure Motion Studio.
- Use Save project for local browser storage.
- Export Project JSON to keep an editable backup.
- Export HTML, SVG, or PNG to share your work.

OFFLINE USE
Open the app once while online so the service worker can cache its core files.
After successful caching, the app can reopen offline in a supported browser.
Browser storage may be cleared by the browser or operating system; keep JSON backups.
