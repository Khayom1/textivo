TEXTIVO — TEXT STUDIO
INSTALLATION & QUICK START · BUILD 15

WHAT YOU NEED
- Python 3
- A modern browser: Chrome, Firefox, Edge, or Safari

RUN ON ANDROID WITH TERMUX
1. Open Termux.
2. Install the required tools:
   pkg update
   pkg install git python
3. Download Textivo:
   git clone https://github.com/Khayom1/textivo.git
4. Enter the folder:
   cd textivo
5. Start the local web server:
   python -m http.server 8080 --bind 127.0.0.1
6. Open this address in your browser:
   http://127.0.0.1:8080

Keep Termux running while you use Textivo. Press CTRL+C in Termux to stop the server.

FIRST PROJECT
- Write your text in the line boxes.
- Use Text tools to count words, search, replace, change case, and clean lines.
- Select a word or character to style it.
- Choose a canvas format and background.
- Preview your text and configure Motion Studio if needed.
- Save the project locally and export a JSON backup.
- Export HTML, SVG, or PNG when you are ready to share.

OFFLINE USE
Open Textivo once while online so the service worker can cache its core files.
After successful caching, the app can reopen offline in a supported browser.
Saved work stays in browser storage on this device. Browser cleanup, private browsing, or operating-system storage management can remove it. Export a Project JSON backup for important work.
